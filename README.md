# REBOOTX

An open-source automation recovery platform. **Implemented: Checkpoint 1 backend foundation only.** Authenticated n8n failure events become durable, tenant-isolated incidents in `RECEIVED` status. Recovery orchestration, AI, adapters, and frontend are planned and are not implemented.

See [backend setup and webhook contract](backend/README.md), [implementation and validation report](backend/IMPLEMENTATION.md), and the unchanged [planning documents](docs/PRD.md).
